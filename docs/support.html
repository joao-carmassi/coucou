FAQ

Where is the Windows download?

It is paused for now. Microsoft Defender wrongly flags the unsigned installer as malware; a false-positive report is under review, and the installer will come back once it is cleared and signed. Until then you can build it from source (npm run pack).

Mochi doesn’t show my Claude Code sessions

Check that the Claude Code module is on in Settings → Módulos. Then Settings → Claude Code → Install hooks…, review the changes, confirm, and start a new Claude Code session. For Claude Code inside WSL, use Settings → WSL.

What does Aguardar do?

It closes the island and leaves the permission request or question pending. Nothing is decided; answer later on the island or in the terminal.

A module or an integration is missing

Timer, Voice and the integrations (GitHub, Vercel, Stripe, n8n, Resend, Cal.com, Notion) are off by default. Turn them on in Settings → Módulos. An integration pill stays grey until its key is entered; keys are stored in the Windows Credential Manager.

Voice input doesn’t work

Voice needs the Claude Code module, English speech, and its model: Settings → Voz → Baixar modelo (about 20 MB, downloaded from huggingface.co). Press the hotkey (default Ctrl+Alt+V) to open the microphone for one phrase. If another program already uses the hotkey, Settings shows the error; pick another combination.

No sound

Check the sound setting in Settings → Geral and the Windows volume.

Where are my files and logs?

Settings: %APPDATA%\Coucou. Dropped files, the voice model, the hook relay and the log: %LOCALAPPDATA%\Coucou (log: coucou.log, restarted past about 1 MB).

How do I uninstall?

Remove the hooks first: Settings → Claude Code → Uninstall (and the same under WSL if you installed them there). Then uninstall Coucou from Windows Settings → Apps. Optionally delete %APPDATA%\Coucou and %LOCALAPPDATA%\Coucou, and your keys in the Credential Manager (entries named fr.louisraille.coucou).

Questions fréquentes

Où est le téléchargement Windows ?

Il est en pause pour le moment. Microsoft Defender détecte à tort l’installeur (non signé) comme un malware ; un signalement de faux positif est en cours d’analyse, et l’installeur reviendra dès que ce sera réglé et signé. En attendant, tu peux le compiler depuis le code source (npm run pack).

Mochi n’affiche pas mes sessions Claude Code

Vérifie que le module Claude Code est activé dans Configurações → Módulos. Puis Configurações → Claude Code → Install hooks…, vérifie les changements, confirme, et lance une nouvelle session Claude Code. Pour Claude Code dans WSL, utilise Configurações → WSL.

Que fait Aguardar ?

Il ferme l’island et laisse la demande de permission ou la question en attente. Rien n’est décidé ; réponds plus tard sur l’island ou dans le terminal.

Un module ou une intégration manque

Timer, Voz et les intégrations (GitHub, Vercel, Stripe, n8n, Resend, Cal.com, Notion) sont désactivés par défaut. Active-les dans Configurações → Módulos. Une pastille d’intégration reste grise tant que sa clé n’est pas saisie ; les clés sont stockées dans le Gestionnaire d’identifiants Windows.

La voix ne marche pas

La voix demande le module Claude Code, de l’anglais parlé, et son modèle : Configurações → Voz → Baixar modelo (environ 20 Mo, téléchargé depuis huggingface.co). Appuie sur le raccourci (par défaut Ctrl+Alt+V) pour ouvrir le micro le temps d’une phrase. Si un autre programme utilise déjà le raccourci, les réglages affichent l’erreur ; choisis une autre combinaison.

Pas de son

Vérifie le réglage du son dans Configurações → Geral et le volume de Windows.

Où sont mes fichiers et mes journaux ?

Réglages : %APPDATA%\Coucou. Fichiers déposés, modèle vocal, relais des hooks et journal : %LOCALAPPDATA%\Coucou (journal : coucou.log, repart de zéro au-delà d’environ 1 Mo).

Comment désinstaller ?

Retire d’abord les hooks : Configurações → Claude Code → Uninstall (et la même chose sous WSL si tu les y as installés). Puis désinstalle Coucou depuis Paramètres Windows → Applications. Tu peux aussi supprimer %APPDATA%\Coucou et %LOCALAPPDATA%\Coucou, ainsi que tes clés dans le Gestionnaire d’identifiants (entrées nommées fr.louisraille.coucou).
