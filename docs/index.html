A tiny friend at the top of your screen

Coucou for Windows puts Mochi at the top of your screen. It shows your Claude Code sessions, lets you approve Claude Code’s permission requests and answer its questions from the island, takes dropped files, a timer and voice input, and keeps an eye on GitHub, Vercel, Stripe, n8n, Resend, Cal.com and Notion. Every feature is a module you can switch off. Free and open source.

Build for WindowsView on GitHub
Private by design. No account, no analytics, no tracking, no chat provider, no API key for any AI service. Your keys stay in the Windows Credential Manager. Read the privacy policy.

Requires Windows 10 or 11 (WebView2 ships with both). The downloadable installer is paused for now: Microsoft Defender wrongly flags the unsigned installer, and it will come back once that is fixed. Meanwhile build it from source; it installs for the current user, with no admin prompt.
